The Core Disconnect

Fragmented textbook trading via WhatsApp statuses and physical notice boards creates immense friction for student buyers and sellers.

The Solution

A centralized, native Android ecosystem designed specifically for the University of Fort Hare.

  • Direct peer-to-peer transactions.
  • Zero middleman fees.
  • Clean, high-contrast Material interface.
  • Immediate access to new listings.

Dynamic Listings

Empowering sellers with robust, categorized listing forms.

  • Dynamic stock count tracking.
  • Secure capture of precise Banking Details.
  • Automatic unique IDs via AUTOINCREMENT.
  • Real-time input validation.

Smart Search Engine

Instantaneous data retrieval ensuring buyers never miss a relevant listing.

  • Dual-Search: Filters by Book or Seller.
  • Powered by parameterized LIKE queries.
  • Lag-free scrolling via RecyclerView.
  • Instant Material Dialog pop-ups.

Technical Stack

Frontend

Native Android SDK utilizing Java 17. UI structured with high-contrast XML layouts.

Persistence

On-device SQLite database via DatabaseHelper.java, ensuring zero-latency data integrity.

VCS

Distributed Git workflow tracking feature branches and merging code seamlessly.

Communication

Implicit Android Intents (ACTION_SEND) bridging directly to WhatsApp for negotiation.

Academic Execution

  • Encapsulation & Modularity

    Private variables secured by robust Getter/Setter methods in the Textbook model, enforcing strict OOP principles.

  • Exception Handling

    Targeted try-catch blocks surrounding Price and Copies inputs to trap NumberFormatExceptions, preventing crashes.

  • Duplicate Prevention Engine

    Custom SQLite read-queries intercept and block identical entries (matching Title AND Seller) prior to insertion.

With six engineers, preventing code conflicts was paramount. We assigned distinct modules (UI, Database, Intents) to individual developers, reviewed code locally, and merged seamlessly into the production branch.
